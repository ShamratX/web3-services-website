contract Presale is Ownable, ReentrancyGuard {
    uint256 public immutable rate;
    mapping(address => uint256) public claimable;

    function buy() external payable nonReentrant {
        require(saleOpen, "SALE_CLOSED");
        uint256 amount = msg.value * rate;
        claimable[msg.sender] += amount;
        emit Purchased(msg.sender, msg.value, amount);
    }

FAQ

Web3 development FAQ

The questions clients ask before hiring a smart contract developer.

Which blockchains do you build on?

Every EVM-compatible network — Ethereum, BNB Smart Chain, Polygon, Arbitrum, Base, Optimism and Avalanche. Contracts are written once and deployed with network-specific configuration, so adding a chain later is a config change rather than a rewrite.

Can you build both the contracts and the website?

Yes, and it's the most common request. I deliver the Solidity contracts and the Next.js or React DApp that talks to them — wallet connection, transaction states, admin dashboard — so there's no handoff gap between the two layers.

How long does a token launch or presale take?

A standard ERC20 or BEP20 token with tests and verified deployment usually takes 3 to 5 days. A full multi-chain presale platform with a dashboard, vesting and claims typically runs 2 to 4 weeks depending on scope.

Do you test and audit the contracts you write?

Yes. Every contract ships with a Hardhat or Foundry test suite covering happy paths, access control, edge cases and adversarial scenarios. I also perform a pre-audit hardening pass and can coordinate with a third-party auditor when a launch needs one.

Do I own the source code?

You own 100% of the code, contracts and deployment keys. Everything is delivered in your own private repository with documentation and deployment scripts.

Can you take over an existing project?

Yes. I regularly pick up half-finished contracts and DApps, review what exists, document the gaps, then fix, extend or rebuild the parts that need it.

How do we handle payment?

Milestone-based, split across scope, build and launch. Crypto or bank transfer, whichever suits you.
